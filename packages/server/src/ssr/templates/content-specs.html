specs/auth.mdREQ-AUTH-001

Validate session token on every request

VerifiedP0requirementowned by selva.everified 2h ago
Requirement
The server MUST validate the session token on every authenticated request. Tokens are signed JWTs; validation checks signature, expiry, and the revocation list before any handler runs.
Why it matters
An unvalidated token is an open door. Centralising the check in validateSession keeps every route honest and gives the indexer a single anchor to link against.
Acceptance criteria3 / 3 met
A1Every authenticated route calls validateSession before its handler.
A2Tokens with an invalid signature are rejected with 401.
A3Revoked tokens stop working within 5s of revocation.
